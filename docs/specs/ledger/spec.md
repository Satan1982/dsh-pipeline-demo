# 规格：记账小工具（演示用小型系统）

> 这是「设计院层」的演示样例：三段式规格 → 任务分解 → 流水线执行。

## 背景

想把日常收支记下来，用命令行就能加一笔、看汇总。不装数据库，数据放 JSON 文件。

## 用户故事

- 作为使用者，我能在命令行记一笔收入/支出，并随时查看当月汇总。

## 验收场景（WHEN/THEN）

- **WHEN** 记一笔 `+100 工资` **THEN** 当月收入合计增加 100。
- **WHEN** 记一笔 `-30 午饭` **THEN** 当月支出合计增加 30，结余 = 收入 - 支出。
- **WHEN** 查询不存在的月份 **THEN** 返回空汇总（收入 0 / 支出 0），不报错。

## 非目标

- 不做多用户、不做云同步、不做图表。

## 约束

- 零依赖（只用 Node 内置模块）；数据文件路径可用环境变量覆盖，默认 `data/ledger.json`。
