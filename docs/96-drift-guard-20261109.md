# P5.5 主仓漂移快照 + verify-clean 落地记录（issue #236，2026-11-09）

> 结论：dispatch 现在在任务前后给**主仓**拍快照（`.git/info/exclude` 的 sha256 + `git status -uall --ignored=matching`），
> 提交后比对：exclude 被改、或出现未放行的新 ignored/untracked 条目 → 直接判失败并中止 push；
> 仅含 bless 的提交额外复算一次 `bash scripts/verify.sh`（不带 `--bless`），跑不出 PASS 即标记 head 不可复算。

## 1 问题

`worktreeStatus`（`ci/dispatch.mjs`）只看 worktree 的 `git status --porcelain`，而 porcelain 受 `.git/info/exclude` 影响：
agent 把一行路径写进 exclude，就能让文件从 status 里消失，调度器与评审都看不到。
另一边，任务期间主仓多出被忽略的产物/凭据副本，事后也没有对账记录——run.mjs 的 P5.5 会拒，dispatch 原来不看。
bless 之后 HEAD 能否复算（不带 `--bless` 再跑一遍门禁）也只靠云端 CI。

## 2 落点

| 文件 | 内容 |
| --- | --- |
| `ci/drift-guard.mjs`（新） | `ALLOW_PREFIXES` / `parseStatus` / `takeSnapshot` / `lineDiff` / `compareSnapshots` / `formatRepoDrift` / `verifyCleanVerdict` |
| `ci/drift-guard.test.mjs`（新） | 11 个单测：exclude 改动报行、ignored/untracked 新增拦截、既有产物目录放行、verify-clean 判据 |
| `ci/dispatch.mjs`（改） | `setupWorktree` 后取 `driftBefore`；提交后取 `driftAfter` 比对并落 `.logs/repo-drift-issue-<n>-attempt-<m>.json`；`reviewAfterCommit` 通过后对 bless 提交复算 verify-clean |
| `scripts/test-baseline.txt` / `scripts/assert-baseline.txt` | 同 PR bless：445→456 tests，1192→1217 asserts |

## 3 判定口径

| 情形 | 结果 |
| --- | --- |
| `.git/info/exclude` 的 sha256 变化 | BLOCKED，报告 `- 删掉的行` / `+ 新增的行` |
| 主仓新增 `!!`（ignored）或 `??`（untracked）条目，且不在放行目录 | BLOCKED，逐条列出 flag + path |
| 新增条目在 `.logs/`、`.worktrees/`、`dist/`、`.backups/` 下 | 放行（调度链自己的产物） |
| 快照读取/`git status` 失败 | 抛错 → 本次尝试失败（fail-closed，不静默跳过） |
| 提交仅含基线数字（bless） | 复算 `bash scripts/verify.sh`，必须 exit 0 且出现 `VERDICT: PASS` |
| 提交同时改了 `ci/`/`scripts/` 实体文件与基线 | 跳过本地 verify-clean：不以 Administrator 执行 agent 改过的脚本，交给 `allow:gate` 人工评审 + 云端 CI |
| 其它提交 | 门禁字节与 `origin/main` 完全一致，不重复跑 |

## 4 与既有模块的边界

- `ci/drift.mjs`（已有的 `localDrift/formatDrift`）管的是**工作树/本地残留**；本模块管**主仓状态**，导出名用 `formatRepoDrift` 避免撞名。
- 快照只存主仓（`REPO_DIR`）的 exclude 与 status；worktree 的状态仍由 `worktreeStatus` + 评审层负责。

## 5 验证

```
node --test ci/drift-guard.test.mjs      # tests 11 / pass 11 / fail 0
bash scripts/verify.sh --bless          # VERDICT: PASS（456 tests / 1217 asserts）
bash scripts/verify.sh                  # VERDICT: PASS（复算口径，不带 --bless）
```

## 6 已知缺口

- `ci/dispatch.mjs` 的三处接线（快照时机、比对时机、verify-clean 条件）没有单测：dispatch 是带副作用的 CLI、不可导入；
  判定语义全部在 `drift-guard.mjs` 里，并已被 11 个单测覆盖（与 #235 的接线缺口同性质）。
- 主仓 status 是共享状态：同一时刻并行跑的任务如果往放行目录之外写产物，会记到当前任务头上（默认串行，暂不处理）。
